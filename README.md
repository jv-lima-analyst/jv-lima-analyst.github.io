# João Victor Lima · Portfólio

Portfólio pessoal de BI, Dados & IA: Power BI, SQL Server, Microsoft Fabric, automação e soluções com IA aplicadas a dados.

**🔗 Acesse:** https://jv-lima-analyst.github.io

## Stack

HTML, CSS e JavaScript puros, sem frameworks e sem build.

- Conteúdo centralizado em [`js/data.js`](js/data.js): adicionar um projeto é editar um único arquivo
- Tema claro/escuro com variáveis CSS
- Animações com `IntersectionObserver`, respeitando `prefers-reduced-motion`
- Modal nativo com `<dialog>`
- Layout responsivo com CSS Grid

## Rodando localmente

```bash
python -m http.server 5500
# abra http://localhost:5500
```

Detalhes de arquitetura e como evoluir o projeto: [GUIA.md](GUIA.md).
